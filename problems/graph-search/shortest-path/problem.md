# 無向グラフの最短距離

## 想定解答時間

25分

## 目安難易度

LeetCode Easy～Medium相当を想定した練習問題です。プラットフォーム間の公式な難易度換算ではありません。

## 分野

グラフ探索（幅優先探索）

## 問題

`N` 個の頂点と `M` 本の辺からなる無向グラフが与えられます。頂点は `1` から `N` までの番号で表されます。

頂点 `1` から頂点 `N` まで移動するときに通る辺の本数の最小値を求めてください。頂点 `N` に到達できない場合は `-1` を出力してください。

## 入力

標準入力から次の形式で与えられます。

```text
N M
u_1 v_1
u_2 v_2
...
u_M v_M
```

各 `u_i` と `v_i` は、頂点 `u_i` と頂点 `v_i` を結ぶ辺を表します。

## 出力

頂点 `1` から頂点 `N` までの最短距離を1行に出力してください。到達できない場合は `-1` を出力してください。

## 制約

- `2 <= N <= 200000`
- `0 <= M <= 200000`
- `1 <= u_i, v_i <= N`
- 自己ループや同じ頂点対を結ぶ複数の辺が含まれる場合があります。
- 入力はすべて整数です。

## サンプル

入力例:

```text
6 6
1 2
1 3
2 4
3 4
4 5
2 6
```

出力例:

```text
2
```

## 補足

頂点 `1` から `2` を経由して `6` へ進むと、通る辺は2本です。
