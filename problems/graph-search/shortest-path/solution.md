# 解答・解説: 無向グラフの最短距離

## 解法の方針

各辺を両端の頂点の隣接リストへ登録し、頂点 `1` から幅優先探索（BFS）を行います。

始点の距離を0としてキューに入れます。キューから頂点を取り出し、まだ距離が決まっていない隣接頂点を見つけたら、現在の距離に1を足した値をその頂点の距離として設定し、キューに追加します。探索後、頂点 `N` の距離を出力します。未到達を表す初期値が残っていれば `-1` を出力します。

## 正当性

BFSは始点からの距離が小さい頂点から順に処理します。距離 `d` の頂点を処理して初めて発見される隣接頂点は、距離 `d + 1` で到達できます。それより短い経路があるなら、その経路上の直前の頂点は先に処理されるため、より早く発見されているはずです。したがって各頂点に最初に設定される距離は最短距離です。

頂点 `N` が探索されなかった場合は、頂点 `1` から到達する経路がありません。よって `-1` が正しい結果です。

## 計算量

- 時間計算量: `O(N + M)`
- 空間計算量: `O(N + M)`

## Java 解答例

学習者が回答を書くファイルは `src/main/java/Main.java` です。完成した模範解答は `src/main/java/reference/ReferenceMain.java` に分けています。

## 実装上の注意

- 無向辺は隣接リストの両端へ登録します。
- 距離が未設定かどうかを判定してからキューへ追加し、循環があっても頂点を重複して探索しないようにします。
- `M = 0` の場合、頂点 `N` は到達不能なので `-1` になります。
