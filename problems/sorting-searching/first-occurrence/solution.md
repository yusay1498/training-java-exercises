# 解答・解説: ソート済み配列から最初の位置を探す

## 解法の方針

二分探索で、`X` 以上の値が初めて現れる位置を探します。探索範囲を半開区間 `[left, right)` で管理し、`A[middle] < X` なら `left` を `middle + 1` へ、そうでなければ `right` を `middle` へ更新します。

探索終了時の `left` は、`X` 以上の値が初めて現れる位置です。その位置が配列の範囲内で、値が `X` と等しければ、1始まりにして出力します。それ以外は `-1` を出力します。

## 正当性

配列は昇順です。`A[middle] < X` のとき、`middle` 以前のすべての要素も `X` 未満なので、答えは `middle + 1` 以降にあります。一方、`A[middle] >= X` のとき、最初の `X` 以上の位置は `middle` より後ろにはありません。したがって各更新後も、最初の `X` 以上の位置は探索区間 `[left, right)` に保たれます。

探索終了時には `left == right` となり、その位置が最初の `X` 以上の位置です。そこに `X` があれば、その左側の値はすべて `X` 未満なので最初の出現位置です。`X` より大きい値、または配列末尾に達している場合は、`X` は存在しません。

## 計算量

- 時間計算量: `O(log N)`
- 空間計算量: `O(1)`

## 実装上の注意

- 重複値の最初の位置を得るため、値が一致しても探索を終了せず左側を調べます。
- 探索後の位置が `N` になる場合があるため、配列を参照する前に範囲を確認します。
- 配列位置は内部で0始まり、出力時に1を足します。
