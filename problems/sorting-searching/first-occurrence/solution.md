# 解答・解説: ソート済み配列から最初の位置を探す

## 解法の方針

二分探索で、`X` 以上の値が初めて現れる位置を探します。探索範囲を半開区間 `[left, right)` で管理し、`A[middle] < X` なら `left` を `middle + 1` へ、そうでなければ `right` を `middle` へ更新します。

探索終了時の `left` は、`X` 以上の値が初めて現れる位置です。その位置が配列の範囲内で、値が `X` と等しければ、1始まりにして出力します。それ以外は `-1` を出力します。

## 正当性

`p` を「`A[p] >= X` を満たす最初の境界位置」と定義します。そのような要素がない場合は `p = N` です。探索する要素の区間は半開区間 `[left, right)` ですが、`p` は要素の添字とは限らない境界位置なので、探索区間に含まれるとは限りません。不変条件は `left <= p <= right` です。

初期状態では `left = 0`、`right = N` なので不変条件が成り立ちます。`A[middle] < X` なら、昇順性から `p > middle` であり、`left` を `middle + 1` に更新しても `left <= p <= right` が保たれます。`A[middle] >= X` なら `p <= middle` なので、`right` を `middle` に更新しても不変条件が保たれます。

ループ終了時には `left == right` となるため、不変条件から `p = left` です。`p < N` かつ `A[p] = X` なら、`p` より前の要素はすべて `X` 未満なので、`p` が `X` の最初の出現位置です。それ以外（`p = N` または `A[p] > X`）では `X` は存在しません。

## 計算量

- 時間計算量: `O(log N)`
- 空間計算量: `O(1)`

## 実装上の注意

- 重複値の最初の位置を得るため、値が一致しても探索を終了せず左側を調べます。
- 探索後の位置が `N` になる場合があるため、配列を参照する前に範囲を確認します。
- 配列位置は内部で0始まり、出力時に1を足します。
