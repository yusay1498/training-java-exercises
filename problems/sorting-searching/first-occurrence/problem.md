# ソート済み配列から最初の位置を探す

## 想定解答時間

20分

## 目安難易度

LeetCode Easy相当を想定した練習問題です。プラットフォーム間の公式な難易度換算ではありません。

## 分野

ソート・探索（二分探索）

## 問題

整数が昇順に並んだ配列 `A` と、検索する整数 `X` が与えられます。`A` の中に `X` が存在する場合、最初に現れる位置を出力してください。存在しない場合は `-1` を出力してください。

位置は1から始まります。同じ値が複数回現れる場合は、そのうち最も左の位置を出力してください。

## 入力

標準入力から次の形式で与えられます。

```text
N X
A_1 A_2 ... A_N
```

## 出力

`X` が配列に存在する場合は最初の位置を1行に出力し、存在しない場合は `-1` を出力してください。

## 制約

- `1 <= N <= 200000`
- `-10^9 <= A_i, X <= 10^9`
- `A_1 <= A_2 <= ... <= A_N`
- 入力はすべて整数です。

## サンプル

入力例:

```text
8 4
1 2 4 4 4 7 9 10
```

出力例:

```text
3
```

## 補足

値 `4` は3回現れますが、最初の位置である3を出力します。
