# 階段の上り方

## 想定解答時間

20分

## 目安難易度

LeetCode Easy相当を想定した練習問題です。プラットフォーム間の公式な難易度換算ではありません。

## 分野

動的計画法

## 問題

`N` 段の階段があります。1回に1段または2段上ることができます。階段の一番下から始めて、ちょうど `N` 段目に到達する方法が何通りあるか求めてください。

上る段数の並びが異なる場合は、異なる方法として数えます。答えは大きくなる可能性があるため、`1,000,000,007` で割った余りを出力してください。

`N = 0` の場合、何も上らない方法を1通りと数えます。

## 入力

標準入力から次の形式で与えられます。

```text
N
```

## 出力

ちょうど `N` 段目に到達する方法の数を `1,000,000,007` で割った余りで出力してください。

## 制約

- `0 <= N <= 1000000`
- 入力は整数です。

## サンプル

入力例:

```text
5
```

出力例:

```text
8
```

## 補足

5段目へは、最後に1段上るか、最後に2段上る方法があります。それぞれの場合の数を合わせると8通りです。
