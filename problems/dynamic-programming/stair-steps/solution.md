# 解答・解説: 階段の上り方

## 解法の方針

`dp[i]` を「ちょうど `i` 段目に到達する方法の数」とします。`i` 段目へは `i - 1` 段目から1段上るか、`i - 2` 段目から2段上る方法で到達するため、`dp[i] = dp[i - 1] + dp[i - 2]` です。

初期値は `dp[0] = 1`、`dp[1] = 1` です。`i` を2から `N` まで順番に計算し、各段階で `1,000,000,007` の剰余を取ります。

## 正当性

階段の `i` 段目に到達する方法は、最後の一歩によって分類できます。最後に1段上った方法は `i - 1` 段目までの各方法に一意に対応し、最後に2段上った方法は `i - 2` 段目までの各方法に一意に対応します。この2つは最後の一歩が異なるため重複せず、他の到達方法もありません。よって `dp[i] = dp[i - 1] + dp[i - 2]` です。

`dp[0] = 1` は何も上らない方法を表し、`dp[1] = 1` は1段上る方法です。したがって、この漸化式を順に計算すれば、各 `i` について正しい方法数が求まります。

## 計算量

- 時間計算量: `O(N)`
- 空間計算量: `O(N)`

## 実装上の注意

- `N = 0` の答えは初期値 `dp[0] = 1` です。
- 加算のたびに剰余を取ります。Javaでは剰余計算の前に2つの値を `long` に拡張して加算します。
- `N = 1` の場合は `dp[1] = 1` を返します。
