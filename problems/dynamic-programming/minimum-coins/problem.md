# 目標額を作る最小の硬貨枚数

## 想定解答時間

25分

## 目安難易度

LeetCode Medium相当を想定した練習問題です。プラットフォーム間の公式な難易度換算ではありません。

## 分野

動的計画法

## 問題

額面の異なる硬貨が `C` 種類あります。それぞれの硬貨は何枚でも使えます。合計が `T` になるように硬貨を選ぶとき、必要な硬貨の最小枚数を求めてください。

ちょうど `T` を作れない場合は `-1` を出力してください。`T = 0` の場合は硬貨を使わないため、`0` を出力します。

## 入力

標準入力から次の形式で与えられます。

```text
C T
d_1 d_2 ... d_C
```

## 出力

合計を `T` にするための最小の硬貨枚数を1行に出力してください。作れない場合は `-1` を出力してください。

## 制約

- `1 <= C <= 100`
- `0 <= T <= 100000`
- `1 <= d_i <= 100000`
- 額面 `d_i` はすべて異なります。
- 入力はすべて整数です。

## サンプル

入力例:

```text
3 6
1 3 4
```

出力例:

```text
2
```

## 補足

硬貨 `3` を2枚使うと合計が6になり、2枚より少ない枚数では作れません。
