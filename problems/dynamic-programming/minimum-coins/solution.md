# 解答・解説: 目標額を作る最小の硬貨枚数

## 解法の方針

`dp[s]` を「合計 `s` を作るために必要な硬貨の最小枚数」とします。`dp[0] = 0` とし、それ以外は作れない状態を表す十分大きな値で初期化します。

金額 `s` を小さい順に調べ、額面 `d` が `s` 以下なら、最後に額面 `d` の硬貨を1枚使う場合を考えます。このとき `dp[s]` を `dp[s - d] + 1` と比較して更新します。すべての金額を計算した後、`dp[T]` が未到達のままなら `-1`、そうでなければその値を出力します。

## 正当性

合計 `s` を作る任意の方法には、最後に使った硬貨が1枚あります。その額面を `d` とすると、残りの合計は `s - d` です。最適な方法で残りを作る枚数は `dp[s - d]` なので、その方法全体の枚数は `dp[s - d] + 1` です。

すべての使用可能な額面 `d <= s` についてこの候補を比較するため、`dp[s]` は合計 `s` を作る最小枚数になります。金額を小さい順に計算するので、各遷移元 `dp[s - d]` はすでに確定しています。したがって `dp[T]` は目標額を作る最小枚数であり、到達不能のままなら作成不可能です。

## 計算量

- 時間計算量: `O(C * T)`
- 空間計算量: `O(T)`

## 実装上の注意

- 各額面の硬貨は何枚でも使えるため、すべての `s` について各額面から遷移を試します。
- `T = 0` では初期値 `dp[0] = 0` がそのまま答えです。
- 額面が目標額より大きい場合、その硬貨からは遷移しません。
