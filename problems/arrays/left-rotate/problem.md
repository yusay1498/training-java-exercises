# 配列を左に巡回シフトする

## 想定解答時間

20分

## 目安難易度

LeetCode Medium相当を想定した練習問題です。プラットフォーム間の公式な難易度換算ではありません。

## 分野

配列・リスト操作

## 問題

整数が `N` 個並んだ配列 `A` があります。配列を左方向に `K` 回、巡回シフトしてください。

左への巡回シフトを1回行うと、先頭の要素を末尾へ移動し、残りの要素を1つずつ左へ移動します。シフト後の配列を出力してください。

`K` が `N` 以上の場合もあります。

## 入力

標準入力から次の形式で与えられます。

```text
N K
A_1 A_2 ... A_N
```

## 出力

シフト後の配列を、空白区切りで1行に出力してください。

## 制約

- `1 <= N <= 200000`
- `0 <= K <= 10^18`
- `-10^9 <= A_i <= 10^9`
- 入力はすべて整数です。

## サンプル

入力例:

```text
7 10
1 2 3 4 5 6 7
```

出力例:

```text
4 5 6 7 1 2 3
```

## 補足

10回のシフトは、配列の長さ7で割った余りである3回のシフトと同じ結果になります。
