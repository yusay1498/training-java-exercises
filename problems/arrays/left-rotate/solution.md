# 解答・解説: 配列を左に巡回シフトする

## 解法の方針

配列の長さを `N` とすると、`N` 回シフトした配列は元に戻ります。そのため、実際に必要なシフト回数は `K % N` 回です。

シフト回数を `R` とし、配列全体を追加配列なしで左回転するために、次の3区間を順に反転します。

1. 先頭 `R` 個
2. 残りの `N - R` 個
3. 配列全体

例えば `[1, 2, 3, 4, 5, 6, 7]` を `R = 3` 回左シフトする場合、3区間の反転後に `[4, 5, 6, 7, 1, 2, 3]` になります。

## 正当性

最初の反転によって先頭区間の順序が逆になり、2番目の反転によって後半区間の順序が逆になります。最後に全体を反転すると、両区間内の要素順が元に戻り、区間の並びだけが入れ替わります。したがって、先頭 `R` 個が末尾へ移り、残りが先頭へ移動するため、左に `R` 回巡回シフトした結果になります。

また、配列長 `N` ごとに元の並びへ戻るため、`K` 回のシフトと `K % N` 回のシフトは同じ結果です。

## 計算量

- 時間計算量: `O(N)`
- 追加の空間計算量: `O(1)`（入力配列をその場で更新します）

## Java 解答例

学習者が回答を書くファイルは `src/main/java/Main.java` です。完成した模範解答は `src/main/java/reference/ReferenceMain.java` に分けています。`K` は `10^18` まで取り得るため、`long` として読み込みます。

## 実装上の注意

- `N` が1でも `K % N` は安全に計算できます。
- `K` は `N` より大きくなるため、必ず `K % N` で正規化します。
- 反転対象が空の区間（`R = 0` など）でも、反転処理が何もしないように境界条件を扱います。
