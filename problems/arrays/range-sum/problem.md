# 区間和クエリ

## 想定解答時間

20分

## 目安難易度

LeetCode Easy相当を想定した練習問題です。プラットフォーム間の公式な難易度換算ではありません。

## 分野

配列・リスト操作（累積和）

## 問題

整数列 `A` と `Q` 個のクエリが与えられます。各クエリでは区間 `[L, R]` が指定されるので、その区間に含まれる要素の合計を出力してください。

区間の両端 `L` と `R` を含めて合計します。位置は1から始まります。

## 入力

標準入力から次の形式で与えられます。

```text
N Q
A_1 A_2 ... A_N
L_1 R_1
L_2 R_2
...
L_Q R_Q
```

## 出力

各クエリの区間和を、入力された順に1行ずつ出力してください。

## 制約

- `1 <= N <= 200000`
- `1 <= Q <= 200000`
- `-10^9 <= A_i <= 10^9`
- `1 <= L_j <= R_j <= N`
- 入力はすべて整数です。

## サンプル

入力例:

```text
5 3
3 -1 4 1 5
1 3
2 5
4 4
```

出力例:

```text
6
9
1
```

## 補足

2つ目のクエリは `-1 + 4 + 1 + 5 = 9` です。
