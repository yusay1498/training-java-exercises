# 解答・解説: 区間和クエリ

## 解法の方針

累積和 `prefix` を用意し、`prefix[i]` を先頭から `i` 個の要素の合計とします。`prefix[0] = 0` とし、`prefix[i + 1] = prefix[i] + A[i]` で計算します。

1始まりの区間 `[L, R]` の合計は `prefix[R] - prefix[L - 1]` です。累積和を一度作れば、各クエリを定数時間で処理できます。

## 正当性

`prefix[R]` は `A_1` から `A_R` までの合計で、`prefix[L - 1]` は `A_1` から `A_{L-1}` までの合計です。前者から後者を引くと、両方に含まれる先頭部分が取り除かれ、`A_L` から `A_R` までの合計だけが残ります。よって各クエリで正しい区間和が得られます。

## 計算量

- 前処理: `O(N)`
- クエリ処理: `O(Q)`
- 空間計算量: `O(N)`

## 実装上の注意

- 要素の絶対値は最大 `10^9`、個数は最大 `200000` なので、合計は `int` の範囲を超える可能性があります。累積和と出力は `long` で扱います。
- `prefix` の長さを `N + 1` にすると、先頭からの区間も同じ式で扱えます。
- 入力位置は1始まりです。Java配列の添字に変換するときは累積和の式と対応させてください。
