# 目標値になる2つの位置

## 想定解答時間

20分

## 目安難易度

LeetCode Easy相当を想定した練習問題です。プラットフォーム間の公式な難易度換算ではありません。

## 分野

ハッシュマップ

## 問題

整数列 `A` と整数 `T` が与えられます。異なる2つの位置 `i`, `j` を選び、`A_i + A_j = T` となる組を1つ出力してください。

有効な組が複数ある場合は、どの組を出力しても構いません。有効な組が存在しない場合は `-1 -1` を出力してください。

位置は1から始まります。同じ位置を2回選ぶことはできませんが、異なる位置に同じ値がある場合は選べます。

## 入力

標準入力から次の形式で与えられます。

```text
N T
A_1 A_2 ... A_N
```

## 出力

条件を満たす位置 `i`, `j` を `i j` の形式で1行に出力してください。組が存在しない場合は `-1 -1` を出力してください。

## 制約

- `2 <= N <= 200000`
- `-10^9 <= A_i <= 10^9`
- `-2 * 10^9 <= T <= 2 * 10^9`
- 入力はすべて整数です。

## サンプル

入力例:

```text
5 9
2 7 11 15 1
```

出力例:

```text
1 2
```

## 補足

サンプルでは `A_1 + A_2 = 2 + 7 = 9` です。
