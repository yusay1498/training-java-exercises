# 解答・解説: 目標値になる2つの位置

## 解法の方針

配列を左から順に走査します。現在の値を `A_j` とすると、組になる値は `T - A_j` です。

ハッシュマップに、これまでに見た値とその位置を保存します。各位置で補数 `T - A_j` がマップにあれば、その位置と現在の位置が答えです。なければ現在の値と位置をマップへ追加し、次の要素へ進みます。

補数と値は `long` として扱います。これにより、引き算の中間値で整数オーバーフローが起きません。

## 正当性

位置 `j` を処理する時点で、マップには `j` より前の位置にある値だけが保存されています。補数 `T - A_j` が見つかった場合、その保存位置 `i` は `i < j` であり、`A_i = T - A_j` です。したがって `A_i + A_j = T` を満たす異なる2位置が得られます。

一方、答えとなる組が存在するなら、そのうち後ろ側の位置を処理するとき、前側の値はすでにマップに保存されています。その値が補数として見つかるため、組を出力できます。最後まで見つからなければ条件を満たす組は存在しません。

## 計算量

- 時間計算量: `O(N)`（ハッシュマップの操作は平均 `O(1)`）
- 空間計算量: `O(N)`

学習者が回答を書くファイルは `src/main/java/Main.java` です。完成した模範解答は `src/main/java/reference/ReferenceMain.java` に分けています。

## 実装上の注意

- 現在の値をマップへ登録する前に補数を検索します。これにより同じ位置を2回使うことを防ぎます。
- 同じ値が複数回現れる場合もあるため、位置ごとに処理します。
- 出力位置は問題文に合わせて1始まりに変換します。
